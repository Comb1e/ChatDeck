# ChatDeck v0.1.1 — 打包为可双击运行的 exe

## 目标
用 electron-builder 把 ChatDeck 打包成 Windows 可执行文件,产出两种形态(一次构建同时生成,覆盖两种使用习惯):
- **`ChatDeck-0.1.1-Portable.exe`** — 单文件免安装,鼠标双击直接运行(最贴合"一个 exe 文件双击运行"的需求,作为主交付物)
- **`ChatDeck-Setup-0.1.1.exe`** — 一键安装器(装到 %LOCALAPPDATA%\Programs\ChatDeck,自动创建桌面/开始菜单快捷方式,无需管理员权限)

调研确认:生产代码已就绪(`resourceFile` 走 `process.resourcesPath`、`loadFile('../renderer/index.html')`),与 electron-builder 布局天然匹配,**无需改动任何应用代码**,全部是配置层工作。

## 实施步骤

### 1. 安装依赖(devDependencies)
`electron-builder@^26`、`cross-env`(在 npm script 里设置构建二进制镜像)、`pngjs` + `png-to-ico`(纯 JS,用于生成图标,不引入原生依赖)。

### 2. 生成应用图标 `build/icon.ico`
目前项目无任何图标,不处理会用默认 Electron 图标。新增一次性脚本 `scripts/make-icon.mjs`:纯像素数学绘制 Claude 风格图标 — 赤陶色 `#D97757` 圆角方块 + 两个米白 `#FAF9F5` 圆角竖窗格(分屏对比意象),3×3 超采样抗锯齿,按 [16,24,32,48,64,128,256] 七个尺寸直接绘制并嵌入单个 .ico。

### 3. 新建 `electron-builder.yml`
- `appId: com.chatdeck.app`、`productName: ChatDeck`
- `files: [out/**]`(asar 默认开启,无原生模块,不需 unpack)
- `extraResources: resources → resources`(error.html + 两个 .default.json 平铺拷到安装目录 resources 下,与 `resourceFile()` 的读取路径一致)
- `electronDownload.mirror` 指向 npmmirror;`cross-env` 设 `ELECTRON_BUILDER_BINARIES_MIRROR` 指向 npmmirror 的 electron-builder-binaries(NSIS/winCodeSign 二进制国内镜像)
- `win.icon: build/icon.ico`,targets: nsis + portable(x64)

### 4. package.json 调整
- version 升到 **0.1.1**
- 新增脚本:`"dist": "npm run build && electron-builder --win"`、`"dist:dir": "npm run build && electron-builder --dir"`(快速产出免解包的 win-unpacked,便于冒烟测试)

### 5. 构建与验证(防放宽约束)
1. 回归:`npm run typecheck` + `npm run test`(49 个用例)照常通过
2. `npm run dist` 产出两个 exe;确认 `dist/win-unpacked/resources/` 下存在 error.html 与两个 .default.json
3. **GUI 冒烟测试**:启动 `win-unpacked\ChatDeck.exe` — 窗口出现、侧边栏渲染出 10 个内置厂商(验证 extraResources 生效)、点击任一厂商真实加载网页(验证 renderer/视图链路);再双击启动一次验证单实例锁聚焦已有窗口;portable exe 同样启动确认可跑
4. 已知限制记录到文档:exe 未做代码签名,首次运行 Windows SmartScreen 可能提示「仍要运行」;portable 首次启动需自解压略慢

### 6. 文档与提交
- `docs/iteration.md` 新增 v0.1.1 条目(上版遗留:未打包 → 本版方案 → 验证结果 → 遗留:签名/自动更新)
- `docs/architecture.md` 补充打包与分发小节(extraResources 布局、userData 仍为 %APPDATA%\chatdeck,登录态与开发版互通)
- README 补充双击运行说明(dist 产物路径)
- git 提交到 main
