# ChatDeck v0.3.0 — 悬浮窗划词翻译（百度翻译 API · Ctrl+Q 全局取词）

## 目标
- 全局快捷键 **Ctrl+Q**：在任意应用里鼠标划选文字后按下，即在**悬浮窗正上方**弹出平时隐藏的译文小窗，**只显示译文**（不显示原文）。
- 方向默认**自动**（检测为中文→译英，否则→译中）；弹窗头部提供语言方向选择器，除自动外含常用语种（中⇄英/日/韩、中→俄/法/德/西）。
- 翻译走**百度翻译通用 API**（非 LLM）；**APPID/KEY 由用户在主窗口设置界面填写**，存本地 `translate.user.json`，不进源码、不用 .env。
- 弹窗不抢焦点（showInactive）、Esc/✕/失焦/约10s 自动隐藏；悬浮窗移动时弹窗跟随重新定位，悬浮窗隐藏时弹窗随之隐藏；悬浮窗未唤起时 Ctrl+Q 无动作。

## 调研记录
- 参考项目 `E:\Projects\ChineseHoverTranslator`（Chrome MV3 扩展，无构建无依赖）：百度 API 调用范式直接借鉴——`GET https://fanyi-api.baidu.com/api/trans/vip/translate`，参数 `q/from/to/appid/salt/sign`，`salt=Date.now().toString()`，`sign=MD5(appid+q+salt+key)`（小写 hex，q 用原文参与拼接），AbortController 15s 超时，单次 5000 字上限，`from:'auto'` 交给百度服务端检测并从响应 `from` 回读。其取词（DOM Selection API）与弹窗（页面内 DOM）是浏览器专用，Electron 中重做：globalShortcut + 模拟 Ctrl+C 读剪贴板 + 独立 BrowserWindow。它没有自动方向判断（靠手动 Ctrl+Y 切 zh/en），本版按需求自实现。
- Electron 侧：主进程可用全局 fetch（Node 20），MD5 用 `node:crypto`（不移植扩展的 md5.js）；`globalShortcut`/`clipboard.readText/readImage` 为工程首次引入；渲染层 float.html CSP 锁 `'self'`，翻译请求必须放主进程。弹窗窗口模板照抄 floatWindow.ts（transparent + `#00000000` + ready-to-show 再 show + resizable:false + `setAlwaysOnTop('floating')`），弹窗高度 156 > Windows 最小窗高 64，无该踩坑面。

## 架构
```
bootstrap(单实例 + Tray)
├─ FloatWindow(现有) ── float.html ── ViewManager#float
├─ TranslatePopup(新·第三窗) translate.html：常驻惰性创建、平时 hide
│    定位 = 悬浮窗 bounds 正上方居中(间距 8px)；上方放不下→下方 fallback；workArea 夹取
│    悬浮窗 move→跟随，hide→隐藏；永不持久化自己的位置(纯依附)
├─ globalShortcut 'CommandOrControl+Q'（悬浮窗存活时才生效）
│    └─ textCapture：暂存剪贴板(文本+图片)→清空文本→PowerShell SendKeys '^c'→读→无条件还原
├─ TranslateService：translate.user.json(appId/appKey/pair) + 百度 GET
│    node:crypto MD5 签名；请求串行+最小 1.1s 间隔(免费版 QPS=1)；15s 超时
└─ SettingsPanel「划词翻译」section：APPID/KEY 表单

数据流：Ctrl+Q → 主进程取词 → popup.showInactive + 推 {state:'translating'}
      → 百度请求 → 推 {state:'done', dst, dir} | {state:'error', message}
```

## 实施步骤

### 1. 共享层（纯函数，全部可单测）
- `src/shared/translate.ts`（新）：
  - `TRANSLATE_PAIRS: {id, from, to, label}[]` — `auto`(自动·中⇄英)、`zh-en`、`en-zh`、`zh-jp`、`jp-zh`、`zh-kor`、`kor-zh`、`zh-ru`、`zh-fr`、`zh-de`、`zh-es`
  - `resolveDirection(pairId, text)`：auto → 含 CJK（\u4e00-\u9fff/假名/谚文）则 to='en' 否则 to='zh'，from 恒 'auto'；显式语言对直传
  - `buildSign(appid, q, salt, key)`、`joinSegments(trans_result)`（多段 dst 以 \n 连接）、`sanitizeSelection(text)`（trim + 5000 字截断 + 纯空白→null）
  - `TRANSLATE_ERROR_MAP` + `describeTranslateError(code)`：52001 请求超时/52002 系统错误/52003 未授权(查 APPID)/54000 缺参数/54001 签名错误/54003 频率受限/54004 余额不足/58001 方向不支持/58002 服务关闭/58003 文本超长/90107 认证失败，未知码回退「翻译失败（code）」
  - `TRANSLATE_POPUP = {width:320, height:156}` + `translatePopupRect(floatBounds, workArea)`：正上方居中、间距 8px、上方不足→下方、x 夹取工作区
- `src/shared/ipc.ts`：通道 `translate:get-config / translate:save-config / translate:set-pair / translate:get-last / translate:hide` + 事件 `ev:translate-result`
- `src/shared/api.ts`：DeckApi 增 `translate {getConfig, saveConfig, setPair, getLast, hide}` + `on.translateResult`

### 2. 主进程
- `src/main/translateService.ts`（新）：`JsonStore<TranslateConfig>('translate.user.json', {appId:'',appKey:'',pair:'auto'})`；`translate(text)`：fetch GET + URLSearchParams + AbortController 15s，解析 `trans_result` 全量 join；promise 链串行 + `lastCallAt` 保证相邻请求 ≥1.1s；未配置 appId/key → 返回引导错误「请在主窗口设置中填写百度翻译 APPID/KEY」
- `src/main/textCapture.ts`（新）：`captureSelectedText(): Promise<string|null>` — `clipboard.readText()/readImage()` 暂存 → `writeText('')` 清空 → spawn `powershell -NoProfile -NonInteractive -Command "Add-Type -AssemblyName System.Windows.Forms; [System.Windows.Forms.SendKeys]::SendWait('^c')"`（3s 超时）→ 等 ~250ms 读 → **无条件还原**剪贴板 → 返回文本|null
- `src/main/translateWindow.ts`（新）：`TranslatePopupController` — BrowserWindow 参数照抄 floatWindow.ts L113-137（show:false/transparent/hasShadow:false/skipTaskbar/同 preload）；构造依赖 `{getFloatBounds}`；`showAboveFloat()` 用 `translatePopupRect` 定位 + **showInactive()** 不抢焦点；`sendResult()` 缓存 lastPayload 并 `webContents.send(IPC.EvTranslateResult)`（onMounted 前 send 丢失由 `getLast()` invoke 兜底）；`repositionIfVisible()`；`hide()`；显示即重置 ~10s 自动隐藏定时器；`win.on('blur', hide)`；dev F12 DevTools

- `src/main/ipc.ts`：IpcDeps 增 `translate`/`translateWin`；新增 handle(TranslateGetConfig/TranslateSaveConfig/TranslateGetLast) 与 on(TranslateSetPair/TranslateHide)

## 风险与对策
- PowerShell SendKeys 延迟/竞态（触发瞬间切换前台窗口、个别程序 Ctrl+C 非复制）→ 捕获失败静默不弹窗；send 前清空剪贴板避免读到陈旧内容；3s 超时保护
- 剪贴板借用副作用 → 文本+图片无条件还原；富文本/文件等格式丢失记为已知限制（iteration 遗留）
- Ctrl+Q 全局劫持（占用其他应用的退出快捷键）→ 应用运行期间全局生效为明确取舍，README/文档说明；register 失败仅记录不崩溃
- 免费版 QPS=1 → 主进程串行 + 1.1s 最小间隔；54003 映射为友好提示
- 密钥安全 → 仅存 userData 的 translate.user.json，不进源码/git；请求仅主进程发起
- 弹窗正上方空间不足 → 下方 fallback + workArea 夹取（纯函数单测覆盖）
