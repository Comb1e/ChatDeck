# ChatDeck — 国内大模型聚合工作台

一个 Electron 桌面应用：侧边栏切换国内主流 LLM 网页版（登录态持久隔离），支持分屏对比，内置可编辑的预设提示词库，整体 UI 参考 Claude 的简洁风格（米白底色、赤陶色点缀、衬线标题）。

## 技术栈
- **Electron + Vue 3 + TypeScript + electron-vite**（参考同类开源项目 LLM-God、ChatALL 的成熟路线；每站点独立 session/cookie 隔离用 Electron 的 WebContentsView + `persist:` partition，最稳妥）
- Pinia 做状态管理，**手写 CSS 设计令牌**（不引入重型 UI 组件库，保证简洁）
- Vitest 做单元测试

## 核心设计

### 1. 界面布局（Claude 风格）
- 左侧 240px 侧边栏：米白 `#FAF9F5`，顶部衬线字体应用名，下面是厂商列表（圆形图标 + 名称），底部「提示词库」「设置」入口；选中项赤陶色 `#D97757` 左侧指示条
- 主区域：顶部细工具条（当前站点名、分屏按钮 1/2/3、刷新、浏览器打开），下方为网页视图容器
- 分屏：2 列 / 3 列，可拖动分割条调比例，最小窗格宽度保护
- 快捷键：Ctrl+1~9 切换厂商；后台站点的标题变化（如 "(3)" 前缀）在侧边栏图标上显示小红点

### 2. 厂商管理（配置驱动，内置默认 + 用户覆盖）
内置（resources/providers.default.json）：DeepSeek、Kimi、豆包、通义千问、智谱清言、腾讯元宝、文心一言、讯飞星火、海螺AI、秘塔AI搜索。
schema：`{ id, name, url, icon, enabled, userAgent? }`。
设置页可启用/禁用、添加自定义厂商（名称+URL）、清除某站点登录缓存。用户配置存 userData 目录，与内置默认**深度合并**（通用 merge 工具，所有配置复用）。

### 3. WebContentsView 生命周期（状态机）
`idle → attaching → ready ↔ crashed`，显式状态机管理：懒加载（首次点击才创建）、bounds 跟随布局 IPC 同步、崩溃/加载失败给重试页。每个厂商独立 `persist:provider-<id>` partition，登录态持久。

### 4. 布局状态机 + 纯函数切分计算
`single | split2 | split3` 显式状态机；切分矩形计算为纯函数 `computeRects(container, layout, ratios)`，含最小窗格约束，边界情况（容器过小、ratio=0/1）由单测覆盖。

### 5. 预设提示词库
- 内置 24+ 预设，分类：**编程**（写代码/代码审查/解释代码/单测生成/SQL、正则生成/Bug 定位）、**写作**（润色/周报/邮件/文案/会议纪要/PPT大纲）、**翻译**（中译英/英译中/中译日）、**分析**（深度分析/方案对比/数据解读/逻辑校验）、**学习**（费曼讲解/面试准备）、**生活**（行程规划/健身计划/菜谱）
- 支持占位符语法 `{内容}`：点击预设弹出填空框，填完复制
- 每条操作：**复制** / **粘贴到输入框**（利用 Electron `webContents.paste()`，向当前聚焦的站点输入框粘贴，不做 DOM 注入，与纯内嵌模式一致；未聚焦则降级为仅复制）/ 编辑 / 删除
- 提示词存储：内置默认 + 用户自定义合并（同厂商配置机制），设置分类、标题、内容

### 6. IPC 边界
preload contextBridge 暴露：`providers:list|save|delete`、`view:setLayout|reload|back|forward|openExternal|clearData|paste`、`prompts:list|save|delete`、`clipboard`、`onTitleChanged` 事件。渲染层不碰 Node API。

## 实施步骤
1. git init（main 分支）+ electron-vite 脚手架（Vue+TS）+ Vitest
2. 设计令牌 + 侧边栏/厂商列表 UI
3. 主进程：viewManager 状态机 + session 隔离 + bounds 同步 IPC
4. 分屏布局状态机 + 拖动分割 + 单测（computeRects 边界、状态机转移、merge 工具）
5. 提示词库：默认预设数据 + 面板 UI + 编辑器 + 复制/粘贴行为
6. 设置页：厂商启停、自定义厂商、清缓存
7. docs/architecture.md（架构图/数据流/状态机）+ docs/iteration.md（v0.1.0）+ README
8. 验证：单测全过 + `npm run build` 通过 + 启动 dev 实测（侧边栏渲染、切换站点加载、分屏拖动、提示词复制/粘贴）

## 验证要点（防放宽约束）
- merge 工具：默认+用户覆盖、用户删除内置项、非法输入等边界
- computeRects：容器小于最小宽度×3、ratio 0/1 夹取
- 原站点加载失败（断网/URL 失效）→ 呈现错误页而非白屏，可刷新恢复
